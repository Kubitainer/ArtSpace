# ArtSpace

App Android hecha con **Jetpack Compose** que muestra una galería de obras de arte. Se puede navegar entre ellas con los botones **Previous** y **Next**.

Práctica del módulo de Programación Multimedia y Dispositivos Móviles (2.º DAM).

## Funcionalidades
- Muestra la imagen de la obra, su título, el artista y el año.
- Botones Next y Previous con navegación circular (de la última obra se vuelve a la primera y al revés).
- El estado se conserva al girar la pantalla (`rememberSaveable`).
- Diseño adaptado a móvil y tablet.

## Tecnologías
- Kotlin
- Jetpack Compose y Material 3
